# 🚧 責任境界

## 1. Construction-LegalOps-DX との境界

```text
┌─────────────────────────────────────────┐
│ CTIIP（本システム）                      │
│                                          │
│  技術を探す → 研究する → 競合分析        │
│   → Claim比較 → AI一次レビュー           │
│   → ライセンス候補 → 技術部門判断        │
└──────────────┬──────────────────────────┘
               │  ← 責任境界。人のGOが出たときのみ通過
┌──────────────▼──────────────────────────┐
│ Construction-LegalOps-DX                 │
│                                          │
│  正式法務審査 → NDA → 交渉 → 契約        │
│   → ライセンス契約 → 権利管理            │
│   → ロイヤルティ → 更新・終了            │
└─────────────────────────────────────────┘
```

| 区分 | 正本 |
|---|---|
| 技術・知財インテリジェンス | **CTIIP** |
| 正式契約・法務プロセス | **Construction-LegalOps-DX** |

## 2. 境界を越えるインターフェース

| # | 連携名 | 方向 | 内容 | 契機 |
|---|---|---|---|---|
| I-01 | 法務レビュー依頼 | CTIIP → LegalOps | 案件ID、対象技術、権利者、確認事項、根拠資料 | 技術部門の承認後 |
| I-02 | 法務レビュー結果 | LegalOps → CTIIP | 判定、条件、コメント、次アクション | LegalOps 側の完了時 |
| I-03 | 契約締結通知 | LegalOps → CTIIP | 契約ID、対象特許、利用条件、有効期間 | 契約締結時 |
| I-04 | 権利状態同期 | LegalOps → CTIIP | 自社特許の権利状態変更 | 日次 |

**設計方針**: 連携は非同期メッセージ（キュー）とし、CTIIP から LegalOps のDBを直接参照しない。
詳細は [../30-design/03-api-specification.md](../30-design/03-api-specification.md) の外部連携節を参照。

⚠️ **要決定** — LegalOps 側のAPI仕様・認証方式。Phase 4 開始前に両システム間で確定。

## 3. AI と人の境界

```text
AI が出せるもの          人が決めること
─────────────────      ─────────────────
候補                 →  採用するか
根拠（出典つき）      →  信頼するか
リスクの目安          →  進めるか止めるか
類似度                →  対応が必要か
スコア                →  現場に導入するか
```

| 禁止事項 | 実装上の担保 |
|---|---|
| AIの出力を自動で確定状態にする | ワークフロー上、AI実行後は必ず人の承認ステップを経る |
| 根拠のないAI出力を保存する | `ai_citations` が空の `ai_runs` は `status=invalid` として扱う |
| 類似度を侵害可能性として表示する | UI文言をコンポーネントレベルで固定。自由入力を許さない |
| AI出力をそのまま社外文書へ出す | エクスポート時に透かし・注記を強制付与。RBACでエクスポート権限を分離 |

## 4. 法令・資格に関する境界

| 事項 | 方針 |
|---|---|
| 権利侵害の鑑定 | 行わない。社外への鑑定提供も行わない |
| 出願書類の作成・提出 | 行わない。Claim候補の提示までとする |
| 法律相談への回答 | 行わない。確認事項の整理と質問案の生成までとする |

⚠️ **要決定** — 上記の運用ルールについて、法務部門および外部専門家の確認を Phase 0 で得ること。

## 5. データの正本境界

| データ | 正本 | CTIIP での扱い |
|---|---|---|
| 外部公開特許・論文・NETIS | 各発行元 | 取り込みコピー。出典と取得日時を必ず保持 |
| 自社技術台帳・工法・機械 | **CTIIP** | 正本 |
| 自社発明・出願前情報 | **CTIIP** | 正本。最高機密として扱う |
| 自社特許の権利状態 | LegalOps（法的状態）／CTIIP（技術情報） | 権利状態は I-04 で同期。技術面はCTIIPが正本 |
| 契約・ロイヤルティ | LegalOps | CTIIPは参照のみ。編集不可 |
| 人事・組織情報 | 人事システム | ⚠️ **要決定** — 同期方式（SCIM / CSV / 手動） |
