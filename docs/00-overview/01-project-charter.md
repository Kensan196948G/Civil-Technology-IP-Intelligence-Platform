## 1. 目的

土木・建設会社における **技術開発・研究・知的財産の司令塔** を構築する。

国内外の特許、論文、NETIS、工法、材料、施工事例を単一基盤へ統合し、
「検索 → 理解 → 比較 → 判断 → 発明 → 権利化 → ライセンス → 現場活用」を一本の業務としてつなぐ。

```text
現場の課題 → AI → 世界の技術 → 先行技術分析 → 競合分析 → Claim分析
   → AI模擬審査 → ホワイトスペース → 研究テーマ → 発明 → 出願／ライセンス → 現場適用
```

## 3. スコープ

### 3.1 対象（In Scope）

- 25モジュール（M01〜M25）の設計・実装・運用
- 外部公開データの取り込み（JPO/J-PlatPat系、WIPO、公開論文、NETIS・国交省公開情報）
- `Construction-LegalOps-DX` への引き渡しインターフェース
- `Civil-Research-Patent-Scout` からの資産移管
- Cloudflare / Neon 上での本番運用

### 3.2 対象外（Out of Scope）

| 項目 | 理由・移管先 |
|---|---|
| 正式な法務審査・契約締結・権利管理 | `Construction-LegalOps-DX` の責務 |
| 権利侵害の判断・鑑定 | 有資格者の業務範囲。本システムは判断材料の提供までとする |
| 会計・原価管理との統合 | 別プロジェクト。連携は将来検討 |
| 特許出願書類の自動生成・自動提出 | 品質責任を負えない。Claim候補の提示までとする |
| モバイルネイティブアプリ | Web（レスポンシブ／PWA）で対応する |

| # | 基準 | 判定方法 |

## 7. 設計上の絶対条件

以下は、いかなる実装上の都合によっても緩和しない。

| # | 条件 | 実装への反映 |
|---|---|---|
| 1 | **AIは決定しない** | 承認フローに人の判断ステップを必須配置。AI出力に「判断ではない」旨を常時表示 |
| 2 | **類似率 ≠ 侵害率** | Claim類似度の表示に注記を強制。社外持ち出し文書への転記を制限 |
| 3 | **根拠を必ず残す** | `ai_citations` テーブルを必須。根拠なしのAI出力は保存しない |
| 4 | **誰が・いつ・何を調べたか残す** | `search_queries` / `audit_logs` を全操作で記録 |
| 5 | **未公開発明を守る** | プロジェクト単位の行レベル権限、エクスポート制限、AI送信範囲の制御 |
| 6 | **責任境界を越えない** | 法務判断は `Construction-LegalOps-DX` へ引き渡し。本システムは準備までとする |
