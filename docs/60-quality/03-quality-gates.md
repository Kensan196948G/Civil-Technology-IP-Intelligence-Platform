# 🚦 品質ゲート

## 1. マージ条件（通常PR）

すべて満たすこと。一つでも欠けたらマージしない。

| # | 条件 |
|---|---|
| 1 | 必須CIチェックがすべて成功（lint / typecheck / test / build / secret-scan / dep-audit / db-migrate / e2e / authz-test / provenance-test） |
| 2 | critical / high の脆弱性がゼロ |
| 3 | シークレット・資格情報・個人情報・接続文字列の露出がない |
| 4 | マイグレーションが加算のみ・後方互換のみ |
| 5 | 高リスク変更（§3）に該当しない |
| 6 | PR本文が完備（目的・変更・影響・テスト・セキュリティ・マイグレーション・デプロイ・ロールバック・残課題） |
| 7 | レビュー承認を得ている |
| 8 | 対応する要件ID が記載されている |
| 9 | マージ対象の head SHA と検証済みコミットが一致している |

## 2. STABLE 判定

リリース可能と判断する基準。

```text
test success / lint success / build success / CI success
review OK / security OK / error 0 / blocker 0 / unknown impact 0
```

| 変更規模 | 連続成功回数 | 適用例 |
|---|---|---|
| 小規模 | 2 | 文言修正、軽微なドキュメント |
| 通常 | 3 | 機能追加、不具合修正 |
| 重要 | 5 | 認証、認可、DB、データ移行、AI の判定ロジック |

**MUST**: STABLE 未達でのマージ・デプロイを行わない。

## 3. 高リスク変更（自動マージ対象外）

次は専用PRへ分離し、🔒 明示承認を得る。

| 対象 |
|---|
| 公開DNS・custom domain・production route の変更 |
| 本番シークレットの追加・変更・削除・ローテーション |
| 認証方式・主要な認可モデルの変更 |
| 破壊的マイグレーション・本番データの削除 |
| 課金・契約・費用構造に影響する変更 |
| 外部公開範囲・データ保持期間・監査方式の重大変更 |
| AI送信ポリシーの緩和 |
| 設計上の絶対条件（Provenance、人の判断ステップ、注記表示）に触れる変更 |

## 4. リリースゲート

本番リリース前に次を確認する。

| # | 確認項目 |
|---|---|
| 1 | 回帰テストが通っている |
| 2 | セキュリティレビューを実施した |
| 3 | 監査要件（ログ取得・保持）を満たしている |
| 4 | マイグレーションとロールバック手順を検証した |
| 5 | バックアップまたは復旧地点がある |
| 6 | README・運用手順書・変更履歴を更新した |
| 7 | デプロイ手順とロールバック手順が文書化されている |
| 8 | 監視・アラートが設定されている |
| 9 | 対象アカウント・環境・DB・ドメインを一意に特定できている |
| 10 | 🔒 本番デプロイの承認を得た |

**次のいずれかが残っている場合、リリースしない。**

```text
Critical Security Issue / Failed Test / Failed Build
Open Blocker / Unknown Impact / Unreviewed Change / Unverified Migration
```

## 5. 継続的な品質指標

| 指標 | 頻度 | 目標 |
|---|---|---|
| CI 成功率 | 週次 | ⚠️ 要決定 |
| テストカバレッジ | PR ごと | ⚠️ 要決定 |
| 脆弱性（critical/high） | 日次 | 0 |
| Provenance 充足率 | 日次 | 100% |
| 権限テストの網羅率 | PR ごと | 100%（全セル） |
| フレーキーテスト数 | 週次 | 0 |
| DLQ 滞留 | 日次 | 0 |
| データ品質（欠損率・重複率・分類付与率） | 週次 | ⚠️ 要決定 |

## 6. 自動修復の制御

CI 失敗の修正を無限に繰り返さない。

```text
同一エラー・同一原因が2回連続 → Issue 化して原因分析へ切り替える
修復試行が3回に到達        → 当該タスクを Blocked とし、判断を仰ぐ
```

**MUST**: 原因が分からないまま「通るまで直す」ことをしない。
