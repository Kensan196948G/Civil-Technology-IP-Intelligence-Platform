## 15. 提供が遅れた場合の影響

| 未提供 | 影響 |
|---|---|
| 外部データ源の契約（5-1〜5-7） | **検索対象が自社データのみになり、システムの価値の大半が失われる** |
| IdP 情報（2-1〜2-6） | 本番を公開できない。認証なしでの公開は行わない |
| AI利用ポリシー（4-5） | AI機能を本番で使えない。送信可否を判定できないため |
| 職務発明規程（4-1） | 発明管理モジュールを稼働できない |
| データ分類基準（4-4） | 権限設計が確定せず、機密保護を担保できない |
| 技術の適用条件（7-2） | 現場適用性スコアが AI 推定のみになり、精度が大きく落ちる |
| 保有船舶の諸元（7-4） | 船舶事業部向けの価値が出ない |
| 競合企業リスト（8-1） | 競合分析の名寄せ精度が落ち、集計が信用できなくなる |
| 利用者数・予算（10-7, 10-8） | 非機能目標とコスト上限を設定できない |

**MUST**: 提供が遅れている情報は、フェーズのレビューで必ず報告する。
「揃うまで待つ」のではなく、**代替（ダミー・仮値）で進める範囲と、進められない範囲を明示する**。
