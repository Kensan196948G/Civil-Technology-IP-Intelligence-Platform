# 📝 第一拡張群 FR 草案（M26〜M34・M36・M38・M45・M49）

> 本ファイルは、[05-module-expansion-m26-m50.md](05-module-expansion-m26-m50.md)（M26〜M50 正本）に定義した
> **第一拡張群**（優先順位 1〜10 相当）の機能要件 **FR 草案**です。
>
> - **ステータス: 草案（未採択）**。採否（D-1/D-2）の決裁後に、本ファイルの内容を
>   正規の要件レジストリ `../10-requirements/02-functional-requirements.md`（`FR-Mxx-nnn`）へ昇格します。
> - ID は昇格後も変更しない前提で採番しています。
> - 優先度: MUST（必須）／SHOULD（推奨）／COULD（任意）。Phase 5 = 次期拡張。
> - 全モジュール共通の原則: **AI は決定しない**（判断は人間）。類似度・スコアは根拠と注記を伴って提示する。

---

## M26 Patent Citation Intelligence 🔴

| ID | 要件（草案） | 優先度 |
|---|---|---|
| FR-M26-001 | 特許の後方引用・前方引用・NPL引用（論文等）の関係を保持し、一覧表示する | MUST |
| FR-M26-002 | 引用ネットワークをグラフとして可視化する | SHOULD |
| FR-M26-003 | 重要特許（基盤特許・ハブ・引用急増）をスコアと理由付きで抽出する（決定はしない） | MUST |
| FR-M26-004 | 自社特許を引用している競合企業を検出・提示する | SHOULD |
| FR-M26-005 | 学術論文→特許の技術移転（Paper が引用される特許）を提示する | COULD |
| FR-M26-006 | 分析に使った引用データの取得元・取得日時を記録する（再現性） | MUST |
